## 📌 1. Project Overview

The **United States Top 50 Playlist Performance and Song Popularity Trend Analysis** project is a data analytics application that explores historical music chart data from the United States Top 50 playlist.

The application uses Python and Streamlit to present music trends through an interactive dashboard. It helps users explore song popularity and playlist performance over time using the available dataset.

🔗 **Live Dashboard:** [Open the Streamlit App](https://united-states-top-50-playlist-analysis-4fsw2vmgwm7zmvrjdthsn9.streamlit.app/)

## 🎯 2. Objectives

- Analyze historical United States Top 50 playlist data.
- Understand how song popularity changes over time.
- Identify trends and patterns in playlist performance.
- Present the analysis through an interactive dashboard.
- Practice data loading, cleaning, analysis, and visualization using Python.

## ✨ 3. Features

| Feature | Description |
|---|---|
| Dataset Loading | Loads music chart data from a CSV file. |
| Data Preparation | Cleans column names and prepares date values for analysis. |
| Popularity Analysis | Helps explore song popularity in the dataset. |
| Trend Analysis | Displays historical patterns in playlist performance. |
| Interactive Dashboard | Uses Streamlit to make the analysis easy to explore. |

## ⚙️ 6. Installation Steps

Follow these steps to run the project on your computer.

### Step 1: Clone the Repository

```bash
git clone https://github.com/crohancse2405l8-eng/Atlantic_Project.git
```

### Step 2: Navigate to the Project Folder

```bash
cd Atlantic_Project
```

### Step 3: Create a Virtual Environment

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

### Step 4: Install Required Libraries

```bash
pip install -r requirements.txt
```

Alternatively:

```bash
pip install streamlit pandas
```

### Step 5: Run the Application

```bash
streamlit run app.py
```

Open your browser and visit:

```text
http://localhost:8501
```
